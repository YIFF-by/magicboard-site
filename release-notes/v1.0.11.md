# MagicBoard v1.0.11

发布日期：2026-08-31T14:42:26.361Z
构建编号：magicboard-v1.0.11-20260831144323

### 优化

- 文案拆分、镜头规划、手动新增镜头和 MagicShot 拍摄包不再按文字长度自动猜测时长；未经过人工填写或音频校准的时长统一显示为“未校准”。
- 手动填写与音频校准得到的真实时长会继续保留，镜头列表、时间线、审阅页、CSV、Excel、导演稿和 MagicShot 拍摄包会明确区分真实时长与空缺值。
- 分镜导演稿新增“场景分类”列，方便导演稿与拍摄执行表之间核对室内、室外等场景信息。
- Edge 网页桥接弹窗精简为连接状态、服务地址和“打开 MagicBoard”三个核心操作，移除容易造成干扰的模型网页快捷入口。

### 数据安全

- 首次升级会在本地数据目录生成时长迁移前备份，并只清理无法证明来自人工填写或音频校准的旧自动估算值；账户、工作空间、项目文案、镜头、图片、上传文件和外部数据目录连接保持不变。
