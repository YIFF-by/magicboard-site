# MagicBoard v1.0.25

发布日期：2026-09-18T03:17:13.614Z
构建编号：magicboard-v1.0.25-20260918031821

### 修复与优化

- 移除 MagicBoard 登录、注册、密码保护、会话与账户恢复功能：首次自动建立本机资料，打开即进入工作台，不再受密码、登录次数或过期 Cookie 限制。
- 工作台只允许真实本机连接与可信本机地址；关闭远程工作台，旧登录会话不能绕过限制。保留带令牌的审阅分享及本机 Edge 网桥。
- 设置简化为个人资料、工作空间、数据管理和应用偏好；保留历史成员记录，移除邀请、权限修改、转让和退出登录入口。既有项目、资料归属与旧认证历史不删除。
- 安装包改为四个编号入口，旧账户恢复快捷方式兼容为直接打开工作台；补充首次直入、旧资料升级、失效 Cookie、远程与伪造地址阻断、工作空间隔离、分享和备份恢复测试。
