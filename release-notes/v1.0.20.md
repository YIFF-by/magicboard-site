# MagicBoard v1.0.20

发布日期：2026-09-09T02:44:43.103Z
构建编号：magicboard-v1.0.20-20260909024547

### 优化

- 删除 AI 管理任务标签旁的红色圆点，保留提示词错误说明、标签悬停说明和保存校验；不改变原有布局与按钮尺寸。
- 本次公开包同步包含 v1.0.13–v1.0.14 的保存并发保护：项目自动保存按顺序执行，后台任务会核对最新项目版本，发现冲突时保留较新结果并要求刷新，不再让旧页面静默覆盖结构参数、镜头时长、参考图或审核状态。
- 同步包含 v1.0.16 的镜头规划分页修复：新增独立“跳转”按钮，支持回车、多位页码、越界校正，以及分镜表和时间线一致的分页行为。
- 同步包含 v1.0.17 的统一亮橙操作色，以及 v1.0.18–v1.0.19 的 AI 管理工作区优化：固定任务与保存栏、按需展开模型维护、可切换发送预览，并统一关键按钮尺寸。

### 数据安全

- 本次升级不迁移或改写既有项目；保存冲突时优先保留服务端较新版本，账户、工作空间、项目文案、镜头、参考图、上传文件、参数方案、MagicShot 回传和外部数据目录连接保持不变。
