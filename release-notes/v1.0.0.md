# MagicBoard v1.0.0

发布日期：2026-08-24T02:41:10.352Z
构建编号：magicboard-v1.0.0-20260824024152

### 新增

- 正式独立静态官网，完整复用 MagicBoard 展示界面并提供安装包下载。
- 网页桥接优先的“文案拆分”和“参考图”任务，以及可编辑提示词模板。
- 一键正式发布链路，生成版本 ZIP、Latest ZIP、SHA-256、发布 manifest 和更新说明。

### 优化

- 静态官网改用单一专用 CSS，降低首次打开的样式解析和网络请求负担。
- 卡片跟随改为逐帧调度，屏幕外流光、非活动卡片流光和后台页面动画会自动暂停。
- 本地安装继续使用独立 Node 运行时，并保留 Edge 网页桥接、Whisper 与本地模型能力。

### 数据安全

- 升级安装只替换程序文件，不覆盖现有 `data/store.json`、上传媒体或外部数据连接。
- 正式发布包排除账户密码、会话、API 密钥、用户项目数据和 macOS 元数据文件。
