# MagicBoard v1.0.9

发布日期：2026-08-27T07:09:41.494Z
构建编号：magicboard-v1.0.9-20260827071038

### 修复

- 按当前工作流要求恢复结构审核中的“分行”和“合并”操作：支持在光标位置拆分段落，并将当前段落合并到上一段。
- 恢复结构操作的等宽桌面布局、键盘焦点和无障碍名称；首段“合并”保持禁用，避免无效操作。
- 修正此前错误断言这些功能必须不存在的单元与浏览器测试，并新增真实分行、合并及原文还原回归验证。

### 数据安全

- 分行会按文本比例分配时长和来源区间；合并会迁移关联镜头并标记需要更新，不修改账户、工作空间、图片、上传文件或外部数据目录连接。
- 保持 1.0.8 的桌面端限定、安全下载、原子存储及网页桥接方案；不恢复外部模型 API 服务。
