# MagicBoard v1.0.7

发布日期：2026-08-26T10:10:13.779Z
构建编号：magicboard-v1.0.7-20260826101109

### 新增

- 结构审核重新提供“分行”和“合并”操作，可在光标位置拆分文案，并将当前段落合并到上一段。

### 优化

- 分行与合并按钮改为等宽布局，并与画面职责列使用同一条左右基线；文案输入框同步缩短，结构审核行更规整。
- 参数不符合当前方案时继续保留“待确认”和橙色校验状态，但不再显示重复的“AI 建议”小字。
- 结构审核在桌面、中等宽度和手机尺寸下保持紧凑分页、操作可用与页面无横向溢出。

### 数据安全

- 本次升级只替换程序与界面文件，不修改账户、工作空间、项目、参数方案、图片、上传文件或外部数据目录连接。
