# MagicBoard v1.0.5

发布日期：2026-08-26T02:52:00.561Z
构建编号：magicboard-v1.0.5-20260826025250

### 新增

- 全新安装首次打开时建立本机资料和工作空间，默认无需密码。
- “账户与安全”新增可选密码保护；开启后支持登录、设备会话、成员邀请和角色协作。
- 新增本机一次性账户恢复命令，恢复链接十分钟有效且只能使用一次。
- 新增镜头参数方案，可自动保存五类镜头参数、拖动排序，并在镜头规划时按确认顺序使用。

### 优化

- 删除公共固定账户、登录页账号预填和默认账户恢复入口。
- 个人模式只允许本机进入工作台，局域网仍可使用带随机令牌的审阅分享。
- 正式镜头卡不再展示未确认的 MagicShot Take，并统一卡片高度、手填时长和参数下拉控件。
- 已有参考图不再显示过期的结构提醒，镜头排序状态操作改用更短的标签。
- 模板库按桌面到手机使用四、三、二、一列响应式布局，并压缩模板信息区。

### 数据安全

- 旧公共种子账户会迁移为本机个人模式；修改过的账户及已有成员权限保持受保护模式。
- 升级不修改项目、工作空间、图片、上传文件或外部数据目录连接。
